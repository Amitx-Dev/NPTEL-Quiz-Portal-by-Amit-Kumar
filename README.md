# NPTEL Quiz Portal by Amit Kumar

An interactive, responsive Quiz Web Application designed for **NPTEL Design Thinking** & **Karmic Design Thinking** exam preparation.

Created by **Amit Kumar**.

## Features
- **240+ Curated MCQs** across 3 modules:
  - Core Design Thinking (100 Qs)
  - Practice Set 2 (100 Qs)
  - Karmic Design Thinking & TRIZ (40 Qs)
- **Practice Mode**: Instant answer feedback, detailed explanations, and bookmarking.
- **Exam Simulation Mode**: Timed test environment with question navigator grid and final scorecard.
- **3D Flashcards**: Flip cards for quick active-recall study.
- **Question Bank**: Real-time keyword search across all 240+ questions.
- **Dark/Light Theme**: Sleek glassmorphic design system with Web Audio API sound effects.
